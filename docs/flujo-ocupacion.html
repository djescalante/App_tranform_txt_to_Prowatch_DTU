PW Extended App · Módulo Ocupación Edificios

Del reporte diario de ProWatch (Excel) a consultas, dashboard y exportaciones con control de acceso y bitácora.

Flujo de punta a punta

Pasos

1CargaEl administrador sube uno o varios Excel (.xlsx/.xlsm).
2Archivo repetidoSi el mismo archivo ya se cargó (hash SHA-256), se omite.
3LecturaBusca el encabezado (Nombres + Cédula) aunque haya metadatos arriba.
4DeduplicaciónCada fila tiene una huella; las filas idénticas no se repiten.
5ConsultaDashboard precalculado y búsqueda por fecha, empresa, sede, panel, cédula o nombre.
6ExportaciónExcel o CSV (hasta 500.000 filas) con registro en la bitácora.
