PW EXTENDED APP - PAQUETE DE INSTALACION
========================================

Herramientas de Control de Acceso para ProWatch:
  - Usuarios Retirados DTU (padron de empleados -> archivo para ProWatch DTU)
  - Ocupacion Edificios (consulta de marcaciones de los reportes diarios)

Aplicacion ya compilada. En el servidor NO se necesita el SDK de .NET ni internet.

Requisitos
----------
- Windows Server 2022 o superior (x64). En versiones anteriores el instalador
  habilita TLS 1.2 automaticamente (TLS 1.3 no existe ahi).
- Cuenta con permisos de Administrador.

Instalacion
-----------
1. Copiar esta carpeta completa al servidor, por ejemplo C:\PWExtendedApp\
   (no usar una carpeta de usuario ni una unidad de red).
2. Copiar el padron Empleados.txt dentro de esta carpeta
   (o indicar otra ruta despues, en Administracion).
3. Copiar la base de Ocupacion Edificios (prowatch.db, ~800 MB) en data\
   (o indicar otra ruta con -OcupacionDbPath). Si no se copia, el modulo
   arranca vacio y se llena cargando los Excel desde la app.
4. Clic derecho en Instalar.cmd > "Ejecutar como administrador".
   El instalador:
     - instala el ASP.NET Core Runtime 10 si falta (desde prerequisitos\),
     - genera un certificado HTTPS con el nombre del servidor (certs\),
     - genera el secreto JWT (certs\jwt-secret.txt),
     - elimina el servicio anterior "UsuariosRetiradosDTU" si existe,
     - registra e inicia el servicio "PWExtendedApp" (inicio automatico),
     - abre el puerto 443 en el firewall.
5. Abrir https://NOMBRE-SERVIDOR e ingresar con admin / Admin123!
   CAMBIAR DE INMEDIATO las contrasenas de admin y operador1..operador5
   (operadores: Operador123!).

Despues de instalar
-------------------
- Respaldar la carpeta certs\ (certificado, su contrasena y el secreto JWT).
  Las bases de data\ se respaldan solas cada dia a las 2:00 en data\backups\
  (se conservan 7 copias; prowatch.db ocupa ~800 MB por copia). Conviene copiar
  data\backups\ a otro disco o servidor.
- Las contrasenas iniciales son temporales: cada usuario debe cambiarla en su
  primer ingreso.
- Para quitar la advertencia de certificado en los equipos de los usuarios,
  importar certs\server.cer en "Entidades de certificacion raiz de confianza"
  (o distribuirlo por GPO).
- Al arrancar, el dashboard de Ocupacion Edificios se precalcula en segundo
  plano (~20 s con 1,8 millones de marcaciones).

Otras opciones
--------------
  Instalar.cmd -Port 5001                 usar otro puerto (por defecto 443)
  Instalar.cmd -InputPath D:\x\Empleados.txt -OutputDir D:\x\salidas
  Instalar.cmd -OcupacionDbPath D:\x\prowatch.db
  Instalar.cmd -Action Status             ver estado del servicio
  Instalar.cmd -Action Uninstall          quitar el servicio (conserva datos)
  Limpiar-Servicios.cmd                   quitar el servicio actual y el anterior
                                          (UsuariosRetiradosDTU) y sus reglas de firewall;
                                          con -Simular solo muestra lo que haria

Actualizar a una version nueva: reemplazar solo la carpeta app\ y volver a
ejecutar Instalar.cmd (se conservan data\, certs\ y salidas\).

Carpetas
--------
  app\            aplicacion (no editar)
  prerequisitos\  instalador del ASP.NET Core Runtime 10
  certs\          certificado y secretos (solo Administradores)
  data\           bases de datos (usuarios, historial, Lista VIP, prowatch.db)
  salidas\        archivos generados (DTU, XLSX, TSV)
